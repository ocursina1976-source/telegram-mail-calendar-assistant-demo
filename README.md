# 07_Почта: Telegram-бот для почты и календарей (техническая документация)

Для того, кто обслуживает проект (агент `mail-bot-admin` или любая новая сессия): прочитай этот файл целиком, ничего не переспрашивай у Ольги про уже настроенное.

## Что это
Бот в Telegram, через который Ольга с телефона работает с Яндекс-почтой (личная и рабочая) и календарями (Яндекс личный/рабочий и Google). Работает на её Windows-ПК (бот должен быть запущен, ПК включён). Перенос на VPS отклонён: у сервера 1 ГБ RAM при минимуме 4 ГБ для Claude Code.

## Архитектура
Telegram -> плагин `telegram@claude-plugins-official` (канал) -> сессия Claude Code `claude --model claude-sonnet-5-5 --channels plugin:telegram@claude-plugins-official`, запущенная ярлыком «Бот почты и календаря» на рабочем столе (рабочая папка ярлыка: эта папка) -> инструменты:
- MCP-сервер `yandex` (`yandex-mcp\server.py`, Python, IMAP/CalDAV по паролям приложений Яндекса). Аккаунты `personal` и `work`. Почта: чтение без пометки «прочитано», поиск по всем папкам (кроме Отправленных, Черновиков, Корзины, Спама), черновики. Календарь: чтение и создание. Инструментов отправки и удаления писем нет намеренно.
- Коннектор `claude.ai Google Calendar` (привязан к аккаунту claude.ai, аккаунт <адрес Google-календаря>). Чтение и создание событий. Удаление, изменение и ответ на приглашение запрещены в `.claude\settings.json` (deny).
- Правила поведения бота: `CLAUDE.md` в этой папке (ответы только через инструмент `reply`, запреты, правила создания событий, анализ всех папок).

## Часовой пояс и язык
Екатеринбург (Asia/Yekaterinburg, UTC+5). Русский язык.

## Типовые операции
- Запуск бота: ярлык на рабочем столе. Окно не закрывать. Автозагрузка отключена по желанию Ольги.
- Проверка MCP: `claude mcp list` (из этой папки): `yandex` и `claude.ai Google Calendar` Connected.
- Проверка подключений к Яндексу без Telegram: запустить `yandex-mcp\.venv\Scripts\python.exe` с тестовым скриптом, импортирующим `server`, вывод только счётчики.
- Перерегистрация MCP при смене пути: `claude mcp remove yandex --scope user`, затем `claude mcp add yandex --scope user -- "<путь>\.venv\Scripts\python.exe" "<путь>\server.py"`.
- Переезд папки: `.venv` не переносится (абсолютные пути), пересоздать `python -m venv .venv` и `pip install -r requirements.txt`; обновить рабочую папку ярлыка.
- Версия `mcp` закреплена в `requirements.txt` (`mcp<2`: в 2.x переименован FastMCP).

## Известные грабли (уже наступали)
1. **Опросчики Telegram.** Плагин Telegram забирает сообщения бота (getUpdates). Если запущено несколько сессий Claude Code с включённым плагином, лишние опросчики перехватывают и выбрасывают сообщения: бот «молчит». Поэтому плагин включён ТОЛЬКО в этой папке (`.claude\settings.json`), а в пользовательских настройках (`~\.claude\settings.json`) выключен. Сессии вне этой папки (в том числе Claude Desktop) плагин не запускают. Не включать плагин глобально. Если бот молчит: `Get-CimInstance Win32_Process -Filter "Name='bun.exe'"`, должен быть один процесс `server.ts`.
2. **Ответ только в окне.** Бот должен отвечать инструментом `reply`, иначе ответ виден только в терминале ПК. Правило прописано вверху `CLAUDE.md`. Родительский `CLAUDE.md` хаба (1С) подгружается и сюда, но правила этой папки имеют приоритет.
3. **Скриншоты и токен.** Токен бота не показывать в чате и на скриншотах. Если засветился: BotFather -> `/revoke`, затем `/telegram:configure <новый>` в сессии Claude Code и перезапуск бота.
4. **Изменения правил** (`CLAUDE.md`, `settings.json`) вступают в силу после перезапуска бота (`/exit` и ярлык).
5. **Старая копия проекта** `C:\Личное\CLAUDE\Почта` оставлена на время перехода. После перехода на работу из `C:\AI Projects Hub` отправить в корзину (не удалять безвозвратно). Там тоже лежит копия `.env`.
6. Яндекс иногда даёт разовый сбой IMAP («problems with connection»): повторить через 20 секунд.
7. **Неразрывные пробелы в именах папок.** В именах папок Яндекса бывают неразрывные пробелы (например, «Официальные письма»). Раньше `mail_read` с обычным пробелом в имени падал с «No such folder». Сейчас `server.py` сопоставляет имя папки с `list_folders()` через `_resolve_folder`, поэтому подходит и обычный пробел. Правка вступает в силу после перезапуска бота. Копия старой версии: `yandex-mcp\server.py.bak`.

## Границы (из правил хаба и владельца)
- Не отправлять письма, не удалять и не переносить письма, не помечать прочитанными.
- События создавать только после подтверждения «да». По умолчанию в Google-календаре. Не менять и не удалять существующие.
- Не устанавливать ПО и не менять настройки ПК без подтверждения Ольги.
- Файлы не удалять: в корзину.

## Сводки по расписанию (если настроены)
- 07:30 ежедневно (добавлено 2026-11-17): расписание на сегодня, только календари. Задача «Pochta bot - svodka 07-30», режим `morning`.
- 22:30 ежедневно: расписание на завтра + непрочитанная почта.
- 13:00 по будням: непрочитанная почта.
Реализация: планировщик Windows запускает `scripts\digest.ps1`, он вызывает `claude -p` (только чтение, плагин Telegram выключен) и отправляет результат в чат Ольги через Telegram Bot API (токен берётся из файла плагина во время выполнения). Не зависит от окна бота, но ПК должен быть включён. Подробности в самом скрипте.
